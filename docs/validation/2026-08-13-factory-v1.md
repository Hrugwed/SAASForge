# Factory v1 validation evidence

Date: 2026-08-13

Environment: Windows/PowerShell, Node.js 22.14.0, pnpm 10.28.2, and PostgreSQL 17 in Docker.

## Factory repository

The maintained factory passed formatting, lint, strict type checking, unit tests, the production dependency-license policy, Prisma migration deployment, a production build, and its desktop/mobile Playwright journeys.

## Lean standalone profile

Generated `lean-proof` with analytics only. From a clean generated directory it completed install and setup, reported 76 managed files with zero customizations or deletions, and passed formatting, lint, strict type checking, unit tests, the license policy, and a production build.

## Full standalone profile

Generated `full-proof` with authentication, billing, email, analytics, durable jobs, and private storage. It used its own temporary PostgreSQL database and completed:

- install and safe local setup;
- 170 managed files with zero customizations or deletions;
- schema validation and all three migrations;
- formatting, lint, strict type checking, unit tests, and 19 reviewed license expressions;
- a production build containing the expected auth, billing, readiness, reconciliation, support, jobs, storage, privacy, and legal routes;
- two Playwright journeys: independent product smoke coverage plus account creation and protected-workspace access.

Measured on this machine, the final full-profile generation took about 4 seconds, dependency installation and setup about 32 seconds, core verification about 108 seconds, and Playwright about 15 seconds. Network and cache state materially affect those figures.

## Findings closed during validation

The final proof identified and closed three factory-level issues: generated Next.js declaration files are now excluded from formatting because Next.js rewrites them; two permissive transitive license expressions introduced by a fresh dependency resolution were reviewed, documented, and added to the explicit allowlist; and factory/generated-product Playwright servers now use dedicated test ports and never reuse an unrelated local process.

## Deliberately external acceptance gates

This evidence does not claim that an arbitrary generated product is live or legally approved. Live provider credentials, separate hosted projects, domains, Stripe test/live transactions, signed provider webhook delivery, alert routing, backup restore drills, product-specific abuse controls, legal text, accessibility review, and launch approval must be completed for each real product using `docs/production-readiness.md`.
